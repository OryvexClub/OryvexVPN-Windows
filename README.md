# اپلیکیشن وارپ وی‌پی‌ان - ویندوز

**تولیدکننده داخلی وارپ** - بدون نیاز به سرور خارجی!

## قابلیت‌ها
- ✅ تولید کانفیگ وارپ (بدون نیاز به سرور)
- ✅ اتصال/قطع یک‌کلیک
- ✅ انتخاب نقطه اتصال دلخواه
- ✅ تولید کلید X25519 (محلی)
- ✅ نمایش اطلاعات حساب
- ✅ انتخاب آی‌پی تصادفی / بهترین

## شروع سریع
```bash
flutter pub get
flutter run -d windows
```

## ساخت
```bash
flutter build windows --release
```

## GitHub Actions
با پوشش به شاخه main، برنامه به صورت خودکار ساخته می‌شود.
