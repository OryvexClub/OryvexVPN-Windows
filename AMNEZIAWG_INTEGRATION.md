## Technical Details

### Connection Flow
```
User clicks connect
    ↓
Scan endpoints (parallel latency tests)
    ↓
Select fastest endpoint
    ↓
Register with Cloudflare WARP API
    ↓
Generate AmneziaWG config with obfuscation
    ↓
Install WireGuard/WireSock tunnel service
    ↓
Verify handshake
    ↓
Connected! Start monitoring
```

### Endpoint Selection Algorithm
1. **Parallel scan** of probe endpoints (8.6.112.x, Cloudflare ranges)
2. **Measure actual latency** via socket connection timing
3. **Sort by latency** and select fastest
4. **Fallback** to full endpoint list if probes fail

### Obfuscation Strategy
- **Junk packets** (Jc=4): Add noise to confuse DPI
- **Variable sizes** (Jmin=3, Jmax=8): Randomize packet patterns
- **Magic headers** (H1-H4): Mimic other protocols
- **Init/Response junk** (S1, S2): Obfuscate handshake

## Troubleshooting

### Connection fails?
- Check internet connection
- Verify Windows Firewall allows the app
- Run as Administrator if needed

### No endpoints reachable?
- Your ISP may be blocking Cloudflare ranges
- The app will keep trying different endpoints
- Check if a VPN/proxy is already active

### Build fails on GitHub Actions?
- Check Flutter version compatibility
- Verify all workflow steps completed
- Review Actions logs for specific errors
